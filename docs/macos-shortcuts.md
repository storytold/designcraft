# macOS keyboard conventions

DesignCraft keeps macOS application actions on their familiar shortcuts. Creative
commands that conflict use a Control–Command variant on macOS. Other platforms
keep their existing defaults.

| Application action | macOS |
| --- | --- |
| Settings | ⌘, |
| Hide application | ⌘H |
| Hide others | ⌥⌘H |
| Minimize | ⌘M |
| Close document | ⌘W |
| Quit | ⌘Q |

| Creative action | macOS default | Windows/Linux default |
| --- | --- | --- |
| Frame edges | ⌃⌘H | Ctrl+H |
| High Quality Display | ⌃⌥⌘H | Ctrl+Alt+H |

## Compatibility and customisation

This is a deliberate platform-specific exception to reference-app shortcut parity.
Settings uses ⌘, rather than ⌘K on macOS. The changes apply to defaults; saved
custom assignments are not rewritten. The existing Keyboard Shortcuts editor can
restore a preferred creative binding. Such custom assignments can conflict with
system menu actions; check the effective menu shortcuts after customising them.

The command registry, shortcut editor and displayed menu items use the same defaults.
This change addresses the listed conflicts; it does not certify every shortcut,
keyboard layout, accessibility feature or window behaviour.
