# Print-state export regressions

A synthetic knockout group with overlapping half-opacity yellow and magenta rectangles rendered correctly on screen and through the existing top-level PDF raster fallback. Nesting it inside a normal group bypassed that fallback: the overlap blended instead of knocking out. Independently rasterized with Poppler over white, the overlap changed from RGB (255,127,191) before the fix to (255,127,255), matching the screen.

The export helper now traverses visible group children to bounded depth, captures the affected item in parent-local coordinates and replaces it in its original sibling slot. Ancestor transforms, opacity, blend mode and clipping remain outside the rasterized child. A selected raster ancestor includes its descendants once. Capture retains the complete source document for composition, including story frames outside the group. Replaced text frames remain as nonprinting layout placeholders, so following frames keep their story offsets. The selected item’s own blend mode is applied to its replacement image; it is not baked against a missing backdrop. Existing text-wrap stand-ins are inserted beside the image at the same hierarchy level. Tests cover top-level and nested knockout, two nested levels with ancestor scale/translation/Multiply/opacity, an opaque sibling above, unchanged live document data, own-item Multiply, middle-of-thread captures and nested soft-effect wrap exclusions.

The renderer’s explicit CMYK-view option retains its ink-channel passes when capturing one subtree, with unrelated sibling blends excluded from that capture’s pipeline choice. A synthetic capture/full-context comparison covers this path. The export fallback keeps its existing render options.

The fallback remains a warned 300 ppi image, not native editable knockout content. This change addresses document-spread group children; it does not establish parent-page, anchored-object, arbitrary deep-tree or physical-print parity.

A separate diagnostic omission silently dropped explicit stroke and stroke-gap overprint. Export now emits the existing unsupported-overprint warning when it paints an overprinting stroke or gap (dashes/dots or outlined styles). Before replacing an effect group, a bounded scan preserves warnings from painted descendant fills, strokes and gaps. Inactive flags, nonprinting objects and solid strokes without a painted gap do not produce these new warnings. This does not implement PDF overprint or change automatic black-overprint behavior.

The existing engine PDF backend fixtures and evidence helper are reused. Analytical RGB Multiply and half-opacity controls pass; overprint is tested as an explicitly reported unsupported state. These are synthetic tests inspired by a private INDD/PDF study, not evidence that either defect caused the user's uncertain reference differences. No private documents, font programs or Adobe code are included.

Independent Poppler checks of five synthetic knockout PDFs, including own-item Multiply and transformed ancestors, match the screen within one RGB level at 15 stable interior samples. Transformed boundary pixels can differ through raster interpolation; this check does not establish general visual or print fidelity.
