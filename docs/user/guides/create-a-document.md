Choose **File**, then **New Document…** (Ctrl+N), set the page size and margins, and click **OK**.

Shortcuts on this page use Ctrl. On macOS, use Cmd instead of Ctrl.

## Steps

1. Open the **File** menu and choose **New Document…**. On the start screen you can click **New file** instead.
2. In the **New Document** dialog, pick a **Preset**, or leave it and type your own **Width** and **Height**.
3. Set **Pages**, and tick **Facing Pages** if you want left and right pages side by side as spreads.
4. Set **Columns** and the **Gutter** between them.
5. Set the margins: **Top**, **Bottom**, **Inside** and **Outside**.
6. Set **Bleed** if the document goes to print.
7. Tick **Primary Text Frame** if you want a text frame that fills the margins on each page.
8. Click **OK**.

## Presets

The **Preset** list has these page sizes:

- Print: Letter, Legal, Tabloid, Letter - Half, A3, A4, A5, A6, B5, Business Card, Postcard.
- Web: Web 1920 × 1080, Web 1366 × 768, Web 1024 × 768.
- Mobile: Mobile 1080 × 1920, Mobile 390 × 844, Tablet 1024 × 1366.

Choosing a print preset ticks **Facing Pages**. Web and mobile presets leave it off.

## Quick start from the start screen

The start screen also shows a tile for each print preset under **Start a new document**. Click a tile to make a document at that size with no dialog.

## See a finished layout

Click **Open sample magazine** on the start screen. It opens a magazine with a cover, styled pages, threaded columns, text wrap and swatches, which is a good way to see what DesignCraft can do.

## Next

Save your work with **File**, then **Save** (Ctrl+S). The first save asks where to put the file and suggests a name ending in `.designcraft`.
